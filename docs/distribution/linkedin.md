# LinkedIn — Linkfail

Your README still links to a docs page that 404'd six months ago. Nobody notices until a customer does.

I built Linkfail — a GitHub Action that fails the PR (or opens a weekly Issue) when Markdown links die.

Same job people pay Screaming Frog / site-audit retainers for. Packaged as CI.
